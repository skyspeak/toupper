# 12 · Give away a security page template

Every startup that lands an enterprise deal is soon asked "do you have a
security page?" Most write one in a panic. Give them a good one, free, as a
single HTML file. Each copy that keeps the small credit link sends buyers'
security reviewers, and other founders, back to ToUpper.

**Effort:** done, plus 3 posts · **First signal:** week 2 · **Measure:** leads with `campaign = h12_template`

The template is [`kits/security-page.html`](kits/security-page.html). One file,
no build step, no tracking. It covers compliance, SSO/SCIM/roles/audit logs,
encryption and hosting, AI data use, team practices, and how to report an
issue. Status labels say "In progress" in amber, so it's easy to be honest.

## Step by step

1. **Put it somewhere downloadable:** a public GitHub gist, or in the
   `enterprise-asks` repo from hack 11 under `templates/`.
2. **Take a screenshot** of the filled-in example (open the file in a browser,
   1280px wide) for posts.
3. **Post it** using the copy below, on LinkedIn first, then Indie Hackers and
   any founder community that allows free resources.
4. **Answer "do you have a security page?" threads** with it (see hack 01).
5. **Check who's using it** each month: search GitHub and the web for
   `"Template from ToUpper"`. Email the ones you find (below). Some become
   case studies; some will have questions that become leads.

## Rules for this one

- **The credit link is optional.** Say so in every post. A required link turns
  a gift into a trade.
- **Don't imply ToUpper checked their page.** The template makes no claims
  about the company that uses it.
- **Keep the "delete what isn't true" note** at the top of the file. A
  security page that overstates things hurts the startup in a review.

## What to measure

- Leads tagged `h12_template` (the credit link) and `security_page` as the source.
- Pages found using it, monthly. Ten in the first quarter is a good start.
- Which sections people delete. If most delete "AI features", they're not
  being asked yet; if most keep it, that's a post for hack 05.
